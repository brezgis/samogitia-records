# Lithuanian translation glossary (Plungė baptism register, 1886–1890)

Every Lithuanian translation uses these renderings, so a term is consistent across all
entries and can be corrected everywhere at once. Not reviewed by a native speaker; prepared
following common Lithuanian usage for translated metrical books. Changes go here first.

| Russian (as written) | Lithuanian |

| въ Плунгянскомъ Р.К. Приходскомъ Костелѣ | Plungės Romos katalikų parapijos bažnyčioje |
| Викарнымъ Кс: [name] | kunigas vikaras [name] |
| Альтаристомъ Кс: [name] | kunigas altaristas [name] |
| Настоятелемъ Кс: [name] | klebonas kunigas [name] |
| окрещенъ младенецъ именемъ [NAME] | pakrikštijo kūdikį, vardu [NAME] |
| со всѣми обрядами Таинства | su visomis Sakramento apeigomis |
| Крестьянъ [X]ской волости | [X] valsčiaus valstiečių |
| Каноникъ | kanauninkas; fixed order for a canon parish priest: "klebonas kunigas kanauninkas [name]" |
| Мѣщанъ | miestiečių |
| Дворянъ | bajorų |

| незаконнорожденный сынъ / -ая дочь | nesantuokinis sūnus / nesantuokinė duktė |

| сего Прихода | šios parapijos |

| дѣвицею | mergina |

| [B], [husband]'s супругою / женою | [B], [husband's given name + surname, both genitive] žmona, e.g. "Veronika, Juozapo Bunkaus žmona", "Liudvika, Antano Drymbos žmona" |
| холостымъ | nevedęs |

Months (genitive, for dates): sausio, vasario, kovo, balandžio, gegužės, birželio, liepos,
rugpjūčio, rugsėjo, spalio, lapkričio, gruodžio. Date form: "1888 m. balandžio 13 d." in notes;
"1888 metų balandžio 13 dieną" in the translated sentence.

Clergy: Юзефовичъ = kun. Józefowicz (Juozapavičius is NOT used: names of clergy stay as
commonly recorded, Polish form); Авгулисъ = kun. Augulis; Абрамовичъ = kun. Abramowicz;
Петкевичъ = kun. Petkiewicz.

Places: Плунгяны / Плунгянская = Plungė (Plungės valsčius); Бернатовская = "Bernatovo [?]
valsčiaus" unless certain; Ольсядская = Alsėdžių; Ворнянская = Varnių; Тельши / Тельшевскій =
Telšių (town adjective, never "Telševsko"); Кулевскій приходъ = Kulių parapija; Ретовскій = Rietavo;
Жмудская Кальварія = Žemaičių Kalvarija; Либава = Liepoja. Other villages and townships:
Lithuanian-alphabet transliteration as read, with [?] if unsure; never write a Russian adjective
ending as if it were a Lithuanian genitive.

Clergy names stay in ONE recorded Polish form everywhere: Józefowicz, Augulis, Abramowicz,
Petkiewicz, Beresniewicz, Jacewicz (never Beresnevič/Beresnewicz/Jacevič). Write "kunigas" in
full in the sentence ("kun." only in notes).

## Names

- Lithuanian alphabet transliteration of what is read: ш š, ж ž, ч č, щ šč, ц c, х ch, я ja,
  ю ju, й j, ѣ e, і i, ъ dropped, ы y, е e (ie after a vowel only if written so).
- Given names: the standard Lithuanian form when the reading is clearly that name:
  Юзефъ Juozapas, Янъ Jonas, Антонъ/Антоній Antanas, Казимиръ Kazimieras, Францишекъ Pranciškus,
  Винцентъ Vincentas, Игнацы Ignas, Доминикъ Dominykas, Станиславъ Stanislovas, Матеушъ Motiejus,
  Петръ Petras, Павелъ Povilas, Адамъ Adomas, Андрей Andriejus, Іеронимъ Jeronimas, Изидоръ Izidorius,
  Людвикъ Liudvikas, Томашъ Tomas, Феликсъ Feliksas, Зенонъ Zenonas, Михалъ Mykolas, Мартинъ Martynas,
  Якубъ Jokūbas, Александръ Aleksandras, Алоизій Aloyzas, Климентъ Klemensas;
  Анна Ona, Барбара/Варвара Barbora, Францишка Pranciška, Домицеля Domicelė, Петронеля Petronėlė (with ė: never "Petronelė"),
  Антонина Antanina, Катарина/Катаржина Kotryna, Марьянна Marijona, Марія Marija, Агнешка Agnė,
  Розалія Rozalija, Ельжбета Elžbieta, Юзефа Juozapota, Магдалена Magdalena, Зузанна Zuzana,
  Гелена/Елена Elena, Людвика Liudvika, Констанція Konstancija, Ева Ieva, Текля Tekla, Юліанна Julijona;
  Игнацы/Игнатій Ignas (gen. Igno; never Ignacas/Ignasas), Стефанъ Steponas, Бонифацій Bonifacas,
  Августинъ Augustinas, Бенедиктъ Benediktas. Declined forms follow Lithuanian grammar (Jono, Onos,
  Pranciškaus, Igno).
  Otherwise transliterate and add [?].
- Surnames: Lithuanian-alphabet transliteration in the nominative singular, WITHOUT the Russian
  case ending: Рачковскихъ -> Račkovskis, Шимкусовъ -> Šimkus, Поціусовъ -> Pocius, Рамонасовъ ->
  Ramonas. Suffixes: -скій/-скихъ -> -skis (never -skij/-ski); -ичъ/-ичей -> -ičius (Mickevičius);
  -асъ/-усъ/-исъ/-ысъ keep Lithuanian -as/-us/-is/-ys. Where the base is uncertain write the best
  base plus [?] (Vamis [?]). Never "restore" a Lithuanian original that is not written, and never
  mix a Russian -ov with a Lithuanian ending (no "Daumovas").
- Women's surnames: keep the form written; do not invent -aitė/-ytė/-iūtė/-ienė forms.
- Maiden name after "gim.": ALWAYS the nominative singular base of the written surname, never a
  genitive and never an invented feminine form: изъ Якубовскихъ -> "gim. Jakubovskis",
  изъ Мокусовъ -> "gim. Mockus", изъ Кубиліусовъ -> "gim. Kubilius" (not "gim. Jakubovskio",
  "gim. Mockaus", "gim. Balsaitės").
- Parents (formula "[father] и [mother] изъ [maiden] [surname] законныхъ супруговъ"): the second
  name is the FAMILY surname, the first is the mother's maiden name. Template:
  "[X] valsčiaus valstiečių, teisėtų sutuoktinių [father, gen.] [surname, gen.] ir [mother, gen.],
  gim. [maiden name], sūnus/duktė" — e.g. "teisėtų sutuoktinių Jono Beliavskio [?] ir Veronikos,
  gim. Talimovaitės [?], duktė". The father's surname goes with the father; nothing but the maiden
  name follows "gim.". Unmarried mother: "valstietės [mother, gen.] [surname, gen.] nesantuokinė
  duktė" (no "gim.").
- Dates in the translated sentence use numerals: "1889 metų lapkričio 5 dieną".

## Additions after review round 3 (2026-11-11)

- Twins (близнецы): "pakrikštijo dvynius kūdikius, vardais A ir B"; parents clause
  "sūnus ir duktė (dvyniai), gimę …" / "dukterys (dvynės), gimusios …"; godparents per child.
- Feminine given names: Станислава Stanislava, Тереза Teresė, Уршуля Uršulė, Бенедикта Benedikta,
  Элеонора Eleonora, Агнешка Agnė (gen. Agnės).
- я -> ia, ю -> iu after a consonant (Liasas, not Rjačal); ja / ju at a word start or after a vowel.
- Priest with no rank: "Кс: [name]" -> "kunigas [name]". "въ Плунгянскомъ дворѣ" -> "Plungės dvare".
- Township names: never keep a Russian adjective ending (-skoj, -skago, -o as fake genitive): write
  the base + [?] and use the same form for the same township everywhere.
- The formula always keeps "Romos katalikų" and "Sakramento".

## Open question (for a native reader)

- Mother's maiden name: currently "gim. [surname, nominative]" ("Onos, gim. Mockus"). The round-3
  reviewer argues "iš [surname, genitive plural]" ("Onos iš Mockų") is closer to the Russian
  "изъ Мокусовъ" and more idiomatic for the period, without inventing a feminine form. Book 1
  uses "gim."; a change would be a mechanical second pass.
